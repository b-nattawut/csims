วิธีใช้
  1. กดปุ่ม ข้างช่อง input
  2. เขียนตัวอักษรบน canvas ในป็อปอัพ

  4. คลิกเลือกข้อความที่ถูกต้อง → จะเติมลงช่อง input ให้
  5. เขียนต่อได้เรื่อยๆ ข้อความจะต่อท้ายไปเรื่อยๆ
